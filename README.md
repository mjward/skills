# Skills

Agent skills for Claude Code and Cursor.

| Skill | What it does |
| --- | --- |
| [reply-like-me](reply-like-me/README.md) | Learns how you write from your chat, email and docs, then drafts your replies in your voice. |

To install a skill, copy its folder into `~/.claude/skills/` (Claude Code) or `~/.cursor/skills/` (Cursor).
